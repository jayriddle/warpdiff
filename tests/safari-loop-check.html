Safari loop-restart check

Pick a video, let it loop past the end a few times, and compare muted vs unmuted. Measures the gap between presented frames at each loop wrap.

Native loop = the browser wraps at the end (what a single clip uses today).
Managed wrap = seek back just before the end, the way WarpDiff wraps 2+ clips.
