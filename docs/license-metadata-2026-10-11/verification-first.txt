npm pkg get license private

license = 'UNLICENSED'

SyntaxError: Unexpected token 'l', "license = "... is not valid JSON

The verifier exited 1 before writing verification.json. This did not indicate a repository metadata defect. The corrected invocation explicitly requests JSON:
